POV Live Stream Data Flow

How a video feed moves from a sharer's camera to watchers' screens, and which process owns each piece of state. Three deployable parts sit behind one gateway: a Svelte SPA, a Go control plane and a Rust media plane.

Flows

Each flow is a numbered sequence because the order matters. Endpoints are the ones in the API contracts.

1. Create a room REST

Admin, once per server. Only one room can be open.

  1. SPA sends POST /api/rooms with the server passcode.
  2. Go checks the passcode first, then fails with 409 if a room is already open.
  3. Go stores the room in memory and signs an admin JWT with admin: true and room_id.
  4. SPA keeps the token in localStorage. Go stores no tokens.

2. Discover a room REST

Every client, before it connects to anything.

  1. SPA sends GET /api/rooms/:id.
  2. Go checks the blacklist (403 blacklisted) and the room (404 if missing or closed).
  3. Go calls GET /internal/rooms/:id/publishers on the SFU. If the SFU is down, it returns 502 sfu_unreachable.
  4. Go returns sfu_ws_url, ice_servers and the current publisher list.

3. Publish a feed WS media

A sharer's camera, with simulcast layers h, m and l.

  1. SPA opens the SFU WebSocket and sends join_as_publisher.
  2. SFU replies joined with a peer_id.
  3. SPA sends PUT /api/rooms/:id/streamers/:streamer_id so Go can key the stage on a stable ID.
  4. SPA sends sdp_offer. SFU answers, and ICE trickles both ways.
  5. Media flows over UDP to the SFU. SFU broadcasts publisher_joined to the room.

4. Watch a feed WS media

One peer connection per publisher the watcher selects.

  1. SPA opens the WebSocket and sends join_as_subscriber, then request_track with target_peer.
  2. SFU sends sdp_offer with from_peer. The watcher answers.
  3. SFU forwards the layer it has chosen for this watcher's pairing. Layer changes never renegotiate.
  4. Watcher sends connection_stats. SFU may step the layer down and send connection_quality. A manual set_preferred_layer overrides it.

5. Stage layout SSE

An admin rearranges the stage; every open viewer updates.

  1. Admin sends PUT /api/rooms/:id/stage with X-Admin-Token.
  2. Go replaces the template and placements in memory.
  3. Go's hub pushes stage_updated on each open GET /events stream.
  4. SPA redraws. Out-of-order versions are dropped, and EventSource reconnects on its own.

6. Streamer goes live or offline internal SSE

Only the SFU knows who is connected, so Go asks it.

  1. While at least one events stream is open, Go polls the SFU publisher list every 2 s.
  2. Go compares the result with the last push. Only changed streamers trigger a push.
  3. Go sends stage_updated. The streamer's placement stays and shows greyed out when offline.

7. Block a sharer REST internal

One admin action both kicks and blocks.

  1. Admin sends POST /api/blacklist with the peer_id.
  2. Go asks the SFU for that peer's IP via GET /internal/rooms/:id/peers/:peer_id.
  3. Go updates its in-memory list and rewrites blocklist.conf on the shared volume. A failed write rolls the block back.
  4. The gateway's watcher sees the change, runs nginx -t, then nginx -s reload. From then on the IP gets 403 on every route, including /ws.
  5. Go calls POST .../peers/:peer_id/disconnect so the existing connection drops.

8. Close the room REST internal SSE

Admin ends the session.

  1. Admin sends DELETE /api/rooms/:id.
  2. Go calls POST /internal/rooms/:id/close. SFU sends room_closed to every peer and drops the room.
  3. Go sends room_closed on SSE and clears its room state. The admin token stops matching the open room.

Each piece of state has one owner. Go never tracks media, and the SFU never enforces rooms or the blacklist.

Known gaps

  • Block delay. A block takes effect once the gateway reloads, about a second or two. If the SFU disconnect fails, that socket stays up until it closes.
  • Unsupervised watcher. The gateway's blocklist loop has no supervisor. If it dies, new blocks stop applying until the gateway restarts.
  • Watchers can't be blocked. Only publisher peer_ids appear in the admin view, so only sharers can be blacklisted.
  • No token expiry. Admin tokens last until the room closes.
  • One stream per publisher. A camera and a screen share can't yet be sent as separate tracks.
  • All state is in memory. A Go or SFU restart drops the room, streamers, stage and blacklist.
